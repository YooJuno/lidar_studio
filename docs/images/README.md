# Screenshot credits

`kitti-ground.png`, `kitti-roi.png` and `kitti-detection.png` are actual LiDAR Studio captures of **KITTI Raw**, sequence `2011_09_26_drive_0005_sync`, Velodyne scan `0000000041.bin` (zero-based index 41).

- **Dataset authors:** Andreas Geiger, Philip Lenz, Christoph Stiller and Raquel Urtasun.
- **Reference:** *Vision meets Robotics: The KITTI Dataset*, International Journal of Robotics Research, 2013.
- **Source:** [KITTI Raw](https://www.cvlibs.net/datasets/kitti/raw_data.php), [copyright and citation](https://www.cvlibs.net/datasets/kitti/).
- **License:** the dataset-derived screenshot files are provided under [Creative Commons Attribution–NonCommercial–ShareAlike 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/).

The scans were rendered in LiDAR Studio with FugSeg ground classification, a manually positioned vehicle ROI and CenterPoint tiny predictions, respectively. The images are application examples, not ground-truth labels or benchmark results. Only rendered screenshots are included here; download the dataset and install optional model weights separately.
